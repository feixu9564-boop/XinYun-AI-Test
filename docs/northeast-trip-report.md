# 东北冰雪自驾之旅报告

出发日期建议：2026年12月15日–20日之间从香港出发
全程：约40天、13,500公里、纯开车约220小时

## 去程
太行山挂壁公路 → 北京 → G111 → 坝上 → 阿尔山 → 根河 → 漠河

## 回程
哈尔滨 → 雪乡 → 镜泊湖 → 长白山 → G331鸭绿江边防线 → 丹东 → G228绕渤海一整圈 → 高速回深圳

## ⚠️ 重要：车牌问题
如果越野车是**香港牌照**，港车北上只能在广东省内行驶，开出广东会被注销备案。
解决方案：在深圳租一台内地牌四驱车，或把车托运到哈尔滨。

## 酒店与门票（待购）

### 哈尔滨冰雪大世界
- 第28届，扩至125万平米，新增迪士尼冰雪奇缘区
- 往年开园约12月17日，社区预期12月中下旬
- 官方开园日期尚未官宣 → **出票后立即购买**
- 建议：提前在官方小程序或大麦网关注开票通知

### 雪乡
- 今年升级夜游：花灯区 + 烟花秀
- 12月–1月最绝，建议住2–3晚
- 酒店：雪村镇内或二道白河，提前订，元旦前后涨价严重

### 漠河 / 根河
- 极光季12月–2月，零下20到40度
- 酒店集中在漠河镇，根河选择少，提前锁房
- 加油站间隔远、部分路段无信号，备保温毯和食物

### 长白山
- 北坡天池冰封是12月招牌
- 11月–2月因风雪关闭概率约30–40%，出发当天查官方公告
- 山下温泉酒店（长白山万达、长白山皇冠假日）可作中转

### 镜泊湖
- 冬天封湖后雪景极佳，湖心岛可走冰面
- 镜泊小镇或二道河子住宿

### 丹东 / G228渤海沿海
- G228从山东半岛北岸贴海到辽宁，冬天海面空旷可见盐田候鸟
- 偏北风6–7级、阵风8–9级，海边路段风大路滑
- 丹东鸭绿江断桥、抗美援朝纪念馆值得停留

## 极寒行车准备
- 去年12月黑龙江一次降雪封闭34个高速路段，黑冰和风吹雪是主要杀手
- 越野车有优势但别硬闯
- 备：电瓶保温罩、玻璃水防冻液、应急柴暖或驻车加热、雪铲、拖车绳
