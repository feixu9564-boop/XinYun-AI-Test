## 输入与获取

所有视频/信号在本地。`benchmark.prepare` 只读已有视频与 CSV；不下载数据、不识别人脸、不估计肤色。
研究人员必须先按数据集协议确认使用许可，并在若干帧上人工核验固定的皮肤 ROI（额头/脸颊，避开眼嘴）；
明显运动导致 ROI 离开皮肤的录制应拒绝或另行提供经核验的跟踪裁剪。固定 ROI 不是已验证的人脸检测。
输入 CSV UTF-8：

- 帧时间戳：`timestamp_s`，每个解码帧一行，秒、严格递增；使用采集时间戳/可验证 PTS，不能只按帧序号假定没有掉帧。
- 参考 HR：`timestamp_s,bpm`，来自同步接触式 PPG/ECG 设备的 HR（如获准 UBFC 的参考 HR 列），至少覆盖整个评价窗口；允许 NaN 标记缺测。不是从 RGB 推导的参考。若仅有 PPG/ECG 波形，须先单独验证参考 HR 转换和延迟，本提交没有通用 ECG/逐搏算法。
- 两种时间戳均需转换到以视频起点为0秒的相对时基；`reference_offset_s` 明确指定参考时钟到视频时钟的偏移，`video_time=reference_time+offset`。偏移来源必须写入本地实验记录；未确认同步不得测精度。

示例（先准备获准使用的本地文件）：

```bash
.venv/bin/python -m benchmark.prepare --video data/subject01.avi \
  --timestamps data/subject01-frames.csv --reference data/subject01-hr.csv \
  --roi 100 50 80 40 --out data/subject01.npz
```

导出压缩 NPZ：RGB uint8 `[T,128,128,3]`、逐帧 timestamps、reference_timestamps、reference_bpm；
另存原视频/CSV SHA256、ROI、容器 FPS 和 OpenCV 版本到 NPZ provenance。容器 FPS 只作审计，不替代时间戳。
解码帧数和 sidecar 不一致、ROI 越界或坏文件直接失败。转换器一次装入一个录制，长视频应先按同步规则拆分；16秒窗口之外没有假定无限内存。

## 固定清单与划分

复制 [manifest.example.json](../benchmark/manifest.example.json) 到 `data/manifest.json`，填入实际路径、转换器打印的 NPZ SHA256、
来源、许可/授权记录、真实时长、同步偏移。路径相对清单目录。授权字段是研究者声明，不是程序自动核实的授权。
`subject_id` 必须为跨会话/跨数据集统一的去标识参与者ID，不能为视频ID；所有 train/validation/test 记录均进入泄漏检查。
同参与者不同 split、重复录制ID、无来源/授权、无依据的分层标签直接拒绝整个清单。
哈希不符/文件缺失则保留该录制预定窗口并记为 rejected，不能通过悄悄丢样本改善覆盖率。
固定窗口只由清单声明的 duration 决定；禁止为了排除失败片段而缩短时长。
当前选定四个 checkpoint 的训练集为 PURE，程序阻止 PURE 测试；无原始训练受试者清单，其他数据集的跨库身份重复仍需人工核查。
光照/运动/肤色只允许导入数据集可靠标签及 `label_provenance`；没有标签即不生成该分层。合成静态标签不能用于公平性结论。

## 共同评价窗口

- 每个录制从0秒起不重叠16秒窗口，480点、30 FPS；smoke 每个录制先取第一个窗口，完整运行再取全部完整窗口。
- 不完整尾窗不评价，在 summary 记录排除规则；完整窗口中的无效输入/缺失参考绝不删除。少于16秒录制显式拒绝清单。
- 实际 FPS 用窗口附近时间戳差中位数；按该周期估算掉帧（是估计，非硬件计数），输出最大间隔、重复采样后的独立帧数。
- 原始FPS<12、最大间隔>250ms、两端覆盖不足、任一帧ROI均值亮度<30或>235则拒绝；不是已标定的质量阈值。
- 所有算法使用相同 ROI、相同时间戳最近邻重采样，等距时选前帧；大于250ms缺口不插值伪造连续记录。
- 参考需覆盖窗口两端、间隔≤1.5秒、HR 30–240且没有缺测；对参考设备 HR 线性插值并时间积分取均值。不同于对相位差求HR，窗口 HR 波动可导致该定义与频谱峰不同，需在真人报告披露。
- POS/CHROM：1.6秒局部均值归一、投影/标准差比、Hann 重叠相加；独立研究实现，不保证与上游逐点相同。
- 深度模型采用 inventory 指定 resize/输入布局/归一化。DiffNormalized 为相邻帧差和比除以标准差，末帧补0；Standardized 为整个评价窗 z-score。之后按模型 chunk 分块，尾部复制边缘帧补足、输出裁回原始长度；EfficientPhys 额外重复1帧供内部 diff。导数模型拼接输出后累积和重建，统一去趋势。
- 480帧下 PhysNet/PhysMamba 尾部补32帧，EfficientPhys 补60帧，PhysFormer 不补。分块边界/整窗归一可能影响成绩；这是明确的适配器选择，未证明与上游全流水线数值等价，须后续做同样本对照与敏感性分析。
- 六种输出统一线性去趋势、Hann、FFT，0.7–3Hz峰值×60得到 BPM，16秒频率分辨率3.75 BPM；无峰值插值、谐波消歧。恒定/NaN/短输出失败，不返回替代算法值。

## 结果定义与复现

`windows.jsonl`：每个预定窗口×六算法一行（subject、条件、时间、参考/估计BPM、ok/rejected/blocked/failed、原因、对齐审计、推理秒数）。
`summary.json`：每算法整体/每受试者/每可靠条件 MAE、RMSE、bias（估计−参考）、覆盖率、失败率、平均成功推理耗时；
覆盖率=成功/所有预定窗口，失败率=1−覆盖率（包含拒绝与阻塞），缺少结果的误差为 null，不能解读为0。
计时包含模型专属 resize/normalize/forward/波形HR提取，不含公共视频解码、窗口对齐和一次性模型加载；加载时间和运行总时长单列。
GPU `.cpu()` 同步包含在计时中。硬件/版本、随机种子2026、清单和原始录制哈希、模型校验值/阻塞原因均导出。
输出目录已存在时拒绝覆盖。CLI 只在六算法全部窗口成功时退出0；有任何拒绝/阻塞/失败退出1并保留证据，输入/配置错误退出2。

检查点只按 `weights_only=True` 加载固定的 state_dict，strict=True，不反序列化任意对象。
离线结果可能包含去标识受试者ID和条件，默认也保留本地，不将真人结果自动提交 Git。
无 HRV、呼吸、心理评分、诊断或线上推理接口。
